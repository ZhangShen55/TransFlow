## 用途

定义稳定的 HTTP 契约：将按顺序排列、源语言相互独立的文本片段数组，翻译为每个目标语言对应的有序结果数组。

## ADDED Requirements

### Requirement: 翻译请求校验
服务 MUST（必须）提供 `POST /translate`，接收包含字符串数组 `text` 和唯一目标语言代码数组 `language` 的 JSON 请求。文本条数必须为 1 到配置上限，默认上限为 120；目标语言数量必须为 1 到配置上限，默认上限为 6。

#### Scenario: 接受默认最大文本数量
- **WHEN** 客户端提交 120 条文本，且配置未覆盖默认上限
- **THEN** 服务接受该翻译请求

#### Scenario: 文本数量超过配置上限
- **WHEN** 客户端提交的文本条数超过配置上限
- **THEN** 服务返回 HTTP 422，且不提交翻译任务

#### Scenario: 拒绝重复目标语言
- **WHEN** `language` 数组多次包含同一目标语言代码
- **THEN** 服务返回 HTTP 422，并在校验错误中指出重复项

### Requirement: 支持的目标语言
服务 MUST（必须）接受以下 Hy-MT2 目标语言代码：`zh`、`en`、`fr`、`pt`、`es`、`ja`、`tr`、`ru`、`ar`、`ko`、`th`、`it`、`de`、`vi`、`ms`、`id`、`tl`、`hi`、`zh-Hant`、`pl`、`cs`、`nl`、`km`、`my`、`fa`、`gu`、`ur`、`te`、`mr`、`he`、`bn`、`ta`、`uk`、`bo`、`kk`、`mn`、`ug` 和 `yue`。语言代码必须精确匹配，并映射为模型提示词需要的目标语言全名。

#### Scenario: 阿拉伯语使用标准代码
- **WHEN** 客户端在 `language` 数组中包含 `ar`
- **THEN** 服务将其识别为阿拉伯语，并返回 `language` 为 `ar` 的结果项

#### Scenario: 拒绝颠倒的阿拉伯语代码
- **WHEN** 客户端在 `language` 数组中包含 `ra`
- **THEN** 服务返回 HTTP 422，并指出不支持 `ra`

#### Scenario: 拒绝不支持的语言
- **WHEN** 客户端提交支持集合之外的语言代码
- **THEN** 服务返回 HTTP 422，且不提交翻译任务

### Requirement: 混合源语言翻译
服务 MUST（必须）将每个精确非空文本翻译为全部目标语言，且不要求提供源语言字段。同一请求中的文本可以使用不同源语言，服务必须保持调用方指定的目标语言顺序。

#### Scenario: 请求包含不同源语言
- **WHEN** 一个请求包含非空的中文、英文和法文文本，并请求翻译为 `en` 和 `ar`
- **THEN** 服务为每个非空输入位置返回英语和阿拉伯语译文

#### Scenario: 原文看似与目标语言相同
- **WHEN** 某条非空文本看似已经使用目标语言
- **THEN** 服务仍将其作为翻译请求处理，不自动复制原文

### Requirement: 稳定的结果数量与顺序
对于每个目标语言，服务 MUST（必须）为每个输入 `text` 位置返回且仅返回一个输出位置。结果语言按请求顺序排列，每个语言的内容数组必须保持原始文本索引顺序，不受翻译后端实际完成顺序影响。

#### Scenario: 翻译乱序完成
- **WHEN** 各项翻译的完成顺序与输入索引不同
- **THEN** 响应为每个目标语言按原始文本顺序重组结果

#### Scenario: 原文重复
- **WHEN** 相同原文出现在多个输入索引
- **THEN** 响应为每个索引保留独立输出位置

### Requirement: 精确空字符串保持
值为 `""` 的输入 MUST（必须）在每个目标语言的相同索引输出 `""`，不得替换为生成内容或占位文本。判断此规则前，服务不得裁剪非空输入。

#### Scenario: 可翻译文本前后包含空字符串
- **WHEN** 输入为 `["", "需要翻译", ""]`
- **THEN** 每个目标语言的内容数组均包含三项，索引 0 和 2 的值为 `""`

#### Scenario: 空白字符不是精确空字符串
- **WHEN** 输入项包含一个或多个空白字符
- **THEN** 服务不会通过裁剪将其归类为精确空字符串

### Requirement: 成功响应结构
成功响应 MUST（必须）包含可配置的公开模型名 `model`、唯一请求 `id` 和 `result` 对象。`result` 必须包含 `contents`、Unix 秒整数 `finished_time`、非负整数 `process_time_ms`，以及值为 `finished` 的 `finished_reason`。每个 `contents` 项必须包含目标语言代码 `language` 和对应的有序 `content` 数组。默认公开模型名必须为 `seaCraft-translation-model`。

#### Scenario: 多语言请求成功
- **WHEN** 有效请求的全部翻译均成功完成
- **THEN** 服务返回 HTTP 200，每个目标语言对应一个 `contents` 项，并包含完整成功元数据

#### Scenario: 请求标识唯一
- **WHEN** 两个有效请求完成
- **THEN** 响应中的 `id` 互不相同，且均使用配置的标识前缀

### Requirement: 原子失败与公开错误状态
服务 MUST NOT（不得）返回带有不完整翻译矩阵的 HTTP 200。准入容量耗尽时必须返回 HTTP 429；翻译后端未就绪时返回 HTTP 503；已准入请求超过配置期限时返回 HTTP 504；请求校验失败时返回 HTTP 422。

#### Scenario: 一个翻译单元失败
- **WHEN** 任一必需的非空翻译在重试策略耗尽后仍无法完成
- **THEN** 服务返回非成功响应，且不包含部分翻译结果

#### Scenario: 准入队列已满
- **WHEN** 配置的请求准入容量已经耗尽后又收到有效请求
- **THEN** 服务返回 HTTP 429，且不增加后端任务

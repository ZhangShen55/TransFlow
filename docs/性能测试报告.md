# 性能测试报告

## 测试口径

- 模型：Hz-MT2，vLLM 0.28.0。
- GPU 基准：48GB RTX 4090D，vLLM 显存预算约 16GB。
- 并发：64 个独立上游请求，不是将 64 个请求合并成一个请求。
- 每个请求：60-80 条 `text`，翻译为 `zh,en,fr,es,ru,ar` 六种语言。
- 标准课程：335 个转写片段，作为一节课程等效量。
- 服务配置：`max_num_seqs=512`、`batch_size=32`、`batch_workers=16`。

## 测试结果

### 同一课程重复请求

该场景前缀缓存命中率较高，仅作为短文本性能基准：

| 每请求文本数 | P95 | KV Cache 峰值 | 10 分钟课程等效量 | 结果 |
|---:|---:|---:|---:|---|
| 60 | 46.3 秒 | 10.6% | 约 155 节 | 897/897 成功 |
| 70 | 54.6 秒 | 10.7% | 约 151 节 | 768/768 成功 |
| 80 | 62.2 秒 | 10.8% | 约 151 节 | 651/651 成功 |

该场景折算为约 900-950 节 335 段课程等效量/小时，不能作为多课程生产容量承诺。

### 19 节课混合请求

19 个课程文件共 2,964 条文本，不足 `60 × 64 = 3,840` 条，因此补充 876 条真实课程文本，构造 64 个不同的 60 条请求，共 23,040 个翻译单元。

| 指标 | 结果 |
|---|---:|
| 64 个请求总耗时 | **98.390 秒** |
| P50 / P95 / P99 | 97.967 / 98.360 / 98.366 秒 |
| HTTP 200 | 64/64 |
| 前缀缓存命中率 | 32.097% |
| KV Cache 峰值 | 13.612% |
| GPU 平均利用率 | 97.040% |
| 等待请求峰值 / 抢占 / OOM | 26 / 0 / 0 |

该场景的 4090D 吞吐约为 39.03 条文本/秒，折算为 **约 419 节 335 段课程等效量/小时**，当前应以此作为多课程容量规划基准。

## 显卡容量规划

以下以 19 节课混合请求结果为基准。3090 和 4070 Ti Super 尚未实测，数据为独占 GPU 估算，不能直接作为生产承诺。

| GPU | 335 段课程等效量/小时 | 类型 |
|---|---:|---|
| RTX 4090D（48GB） | 约 419 节 | 实测 |
| RTX 3090（24GB） | 约 189-252 节 | 估算 |
| RTX 4070 Ti Super（16GB） | 约 210-273 节 | 估算 |

建议规划值：4090D 约 419 节/小时、3090 约 220 节/小时、4070 Ti Super 约 240 节/小时。4070 Ti Super 需要重新设置显存比例，并独立测试 `max_num_seqs=256/384/512`。

## 结论与限制

- 64 并发、19 节课混合请求在当前 4090D 上约 98 秒完成一轮，全部成功。
- KV Cache 未达到上限，主要瓶颈是模型生成计算和真实文本的输入输出 token 数。
- 19 节课测试比重复单课测试慢，不仅因为前缀缓存命中率从约 77% 降到 32%，真实文本的平均 token 数也更高。
- 3090、4070 Ti Super 必须使用相同课程样本、六种语言和 64 个不同 payload 重新压测。

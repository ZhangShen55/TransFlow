# 性能测试报告

## 当前容量结论

本结论采用多课程混合、低前缀缓存场景，作为生产容量规划基准。

- 并发：64 个独立上游请求
- 请求规模：每个请求 60 条 `text`
- 目标语言：`zh,en,fr,es,ru,ar`
- 服务配置：`max_num_seqs=512`、`batch_size=32`、`batch_workers=16`
- 标准课程：335 个转写片段

在 48GB RTX 4090D、vLLM 显存预算约 16GB 的条件下：

| 指标 | 结果 |
|---|---:|
| 64 个请求总耗时 | **98.390 秒** |
| P50 / P95 / P99 | 97.967 / 98.360 / 98.366 秒 |
| HTTP 200 | 64/64 |
| 前缀缓存命中率 | 32.097% |
| KV Cache 峰值 | 13.612% |
| GPU 平均利用率 | 97.040% |
| 抢占 / OOM | 0 / 0 |

当前 4090D 吞吐约为 39.03 条文本/秒，即 **约 419 节 335 段课程等效量/小时**。这是当前多课程生产容量规划应采用的基准。

## 显卡容量规划

| GPU | 335 段课程等效量/小时 | 类型 |
|---|---:|---|
| RTX 4090D（48GB） | 约 419 节 | 实测 |
| RTX 3090（24GB） | 约 189-252 节 | 估算 |
| RTX 4070 Ti Super（16GB） | 约 210-273 节 | 估算 |

建议规划值：

```text
RTX 4090D：约 419 节/小时
RTX 3090：约 220 节/小时
RTX 4070 Ti Super：约 240 节/小时
```

3090 和 4070 Ti Super 尚未实测，不能直接作为生产承诺。4070 Ti Super 需要重新设置显存比例，并单独测试 `max_num_seqs=256/384/512`。

## 说明

- 64 并发表示 64 个独立请求同时处理，不是将 64 个请求合并成一个请求。
- KV Cache 未达到上限，当前主要瓶颈是模型生成计算和真实文本的输入输出 token 数。
- 前缀缓存命中率较低时，应使用本报告的 4090D 基准，不使用重复同一短文本时的高吞吐结果。
- 3090、4070 Ti Super 应使用相同模型、请求规模、六种语言和 64 个不同 payload 重新压测。

详细说明见 [benchmark-results.md](benchmark-results.md)，原始数据见 `docs/reports/course-mixed-c64-r64.json`。
